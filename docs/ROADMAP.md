# 로드맵

각 단계는 **그 단계만으로 쓸모가 있어야** 한다. 반쯤 만든 상태로 다음으로 넘어가지 않는다.

---

## 0단계 — 뼈대 (현재)

- [x] 레포 초기화, Claude 작업 규칙(`CLAUDE.md`)
- [x] 기획서 / 아키텍처 / 데이터 모델 / 설계 결정 문서
- [ ] Next.js 프로젝트 스캐폴드, TypeScript·ESLint·Prettier

**완료 조건**: 홈서버에서 컨테이너가 뜨고 로그인된다.

---

## 1단계 — MVP: 기록이 쌓인다

### 1-1. 원격 저장 계층
- [ ] GitHub Contents API 클라이언트 (읽기/쓰기/sha 동시성/409 재시도)
- [ ] 메모리 LRU 캐시 (월 24개 상한) + `index.json` 전량 상주
- [ ] 로컬 쓰기 큐 + 10초 디바운스 플러시 + 지수 백오프
- [ ] `/api/sync/status`, 수동 플러시
- [ ] **원격 장애를 주입한 통합 테스트** — 저장 계층은 장애 경로가 정상 경로만큼 중요하다

### 1-2. 기록 CRUD
- [ ] 엔트리 생성/수정/삭제 API
- [ ] 일 상세 화면 — 시간 슬롯 그리드, 카테고리·태그·텍스트 입력
- [ ] 기록 시간대 설정 (기본 09–18시, 범위 밖 수동 추가)

### 1-3. 달력
- [ ] 월 그리드, 일 셀에 요약 첫 줄 + `…`
- [ ] 주간 요약 상시 노출
- [ ] 카테고리 색, 태그 필터
- [ ] 일 셀 클릭 → 일 상세

### 1-4. 요약
- [ ] Claude API 연동 (`claude-opus-5`, adaptive thinking)
- [ ] 일/주/월 요약 생성 + 수동 수정 + 재생성
- [ ] node-cron 스케줄 (23:50 / 일 23:55 / 말일 23:55)
- [ ] 키 없을 때 수동 폴백

### 1-5. 알람
- [ ] PWA 매니페스트, Service Worker
- [ ] VAPID 키 생성 스크립트, 구독 등록/해제
- [ ] 매시 정각 푸시 (이미 기록된 슬롯은 skip)
- [ ] 알림 클릭 → `/quick?slot=…` 직행
- [ ] iOS 설치 안내

### 1-6. 복구
- [ ] 커밋 이력 조회, 특정 시점 복원
- [ ] 월 1회 `snapshots/` tar.gz
- [ ] 전체 JSON 내보내기

**완료 조건**: 한 달간 실제로 매일 기록을 쌓고, 주간 요약이 자동 생성되며, 서버를 날려도 복구된다.

---

## 2단계 — 커리어 관리

- [ ] 지원 내역: 회사·직무·단계·결과·회고
- [ ] 지원 현황 보드 (단계별 칸반)
- [ ] 이력서 섹션 CRUD + 버전 관리
- [ ] 지원 건 ↔ 이력서 버전 연결

**완료 조건**: 지원한 곳과 그 결과가 한 화면에서 추적된다.

---

## 3단계 — 자동 작성 (이 프로젝트의 목적지)

- [ ] 기간·태그를 지정하면 누적 요약·엔트리를 근거로 **경력기술서 초안 생성**
- [ ] 생성된 문단마다 **근거 기록으로 역추적**(`sourceRange`)
- [ ] 채용공고 텍스트를 넣으면 그에 맞춰 강조점을 바꾼 버전 생성
- [ ] 기술스택별 누적 시간 통계 (태그 집계)

**완료 조건**: 이력서 초안이 기억이 아니라 기록에서 나온다.
